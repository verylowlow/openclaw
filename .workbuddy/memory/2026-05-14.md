# 2026-05-14

## 火山引擎 Realtime Voice Provider 实现

按照 `newcallcall-volcengine-realtime-方案.md` 实现了 OpenClaw 的火山引擎端到端实时语音 API Provider（方案 A，最小可用）。

### 新增文件

- `extensions/volcengine/volc-realtime-protocol.ts` — 火山 Realtime 二进制 WebSocket 协议编解码
  - 帧生成：`buildVolcRealtimeControlFrame()`（控制帧）、`buildVolcRealtimeAudioFrame()`（音频帧）
  - 响应解析：`parseVolcRealtimeResponse()`，支持 SERVER_FULL_RESPONSE / SERVER_ACK / SERVER_ERROR_RESPONSE
  - 对齐 Python 官方示例 `protocol.py` + `realtime_dialog_client.py`

- `extensions/volcengine/volc-realtime-voice-provider.ts` — `RealtimeVoiceProviderPlugin` 实现
  - `VolcengineRealtimeVoiceBridge` 类实现完整 Bridge 生命周期
  - `connect()` → WebSocket → StartConnection(1) → ConnectionStarted(50) → StartSession(100) → SessionStarted(150) → `onReady()`
  - `sendAudio()`：μ-law 8kHz → PCM 8kHz → resample 16kHz → gzip → TaskRequest(200)
  - 下行音频：SERVER_ACK/TTSResponse(352) → gzip 解压 PCM 24kHz → `convertPcmToMulaw8k()` → `onAudio()`
  - 事件映射：ASRInfo(450) 打断清音频、ASRResponse(451)/ChatResponse(550) → `onTranscript()`、TTSEnded(359) → `response.done`
  - `dialog_context.md` 自动读取与注入（默认路径：扩展同级目录）
  - `close()` → FinishSession(102) → FinishConnection(2) → ws.close()

- `extensions/volcengine/dialog_context.md` — 示例对话上下文文件

### 修改文件

- `extensions/volcengine/index.ts` — 增加 `api.registerRealtimeVoiceProvider(buildVolcengineRealtimeVoiceProvider())`

### 关键修复

- 类型检查时发现 `const JSON = 0b0001` 覆盖了全局 `JSON` 对象，导致 `JSON.stringify` / `JSON.parse` 报错。已重命名为 `SERIAL_JSON`。
- 正确处理 `SERVER_ACK`（音频原始 bytes）与 `SERVER_FULL_RESPONSE`（JSON 控制事件）两种服务端响应类型。

### 未修改项目

- `newcallcall` 无需代码修改。它作为 SIP/PSTN 网关继续通过 WebSocket μ-law 与 OpenClaw 交互，音频链路的变更完全发生在 OpenClaw 内部（streaming → realtime provider）。
